# U-10: optional GTA V style keyboard and mouse (LEONIDA_KBM_GTA)

The stand-in pad's keyboard table plays, but not the way PC players expect: there is no mouse look and
the buttons are not where GTA V on PC puts them. `LEONIDA_KBM_GTA=1` (every build, off unless set)
swaps in a GTA V PC style table. Without it the keyboard table and its tests are as before.

Ported from Belobug/VIctory-Belobug-AMD, pull request #295 by zhu1025960209-web.

- `F2` or `` ` `` (`~`) turns mouse look on and hides the cursor inside the window; `Esc`, `P` or
  leaving the window turns it off and the cursor comes back.
- Mouse movement drives the right stick, `I` / `J` / `K` / `L` too. The input poll runs every 8 ms
  while the game can draw at 5 fps, so the mouse speed decays with a 45 ms half-life: a flick lasts
  long enough for the next frame to see it and still settles to zero.
- Left / right mouse button = RT / LT, middle button or `C` = R3, `Shift` = A, `Space` = X, `R` = B,
  `F` = Y, `Tab` = LB, `Q` = RB, `Ctrl` = L3, `E` = D-pad right, `V` = View. W/A/S/D stay the left
  stick.
- `LEONIDA_MOUSE_SENS` scales the mouse speed (default `1.0`); `LEONIDA_MOUSE_INVERT_Y=1` inverts Y.

All three switches are read once and take `1` only, like the other `LEONIDA_*` switches. Switched off,
the input poll reads one flag that stays false and asks Windows for nothing more.

A player turns it on without setting anything by hand with a local profile in
`gpu-profiles.local.json` beside `leonida.toml`, the same way as `skip-scenes`:

```json
{
  "profiles": [
    { "name": "kbm-gta", "env": { "LEONIDA_KBM_GTA": "1" } }
  ]
}
```
